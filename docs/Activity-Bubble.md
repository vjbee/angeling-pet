# บับเบิลกิจกรรมและสถานะ

## สถานะ

| ไอคอน | สถานะ | เกิดเมื่อ | ท่าของ Angeling |
|---|---|---|---|
| ⚙️ | กำลังทำ | ได้รับงาน, รันคำสั่ง, แก้ไฟล์ | วิ่ง |
| 🔍 | ตรวจดู | อ่าน ค้นหาไฟล์ หรือค้นเว็บ | มองหา |
| ⚠️ | ต้องดูตอนนี้ | ขออนุญาต หรือถามคุณ (กรอบแดงกะพริบ) | รอ + `/wah` |
| 😣 | ติดปัญหา | tool ล้มเหลว (กลับเป็น "กำลังทำ" เองหลัง 20 วินาที) | ล้ม + `/omg` |
| ✨ | เสร็จแล้ว | Claude ตอบจบรอบ | กระโดด โบกมือ + `/lv` |
| 💤 | พร้อม | ยังไม่มีงาน | ไม่แสดงในบับเบิล |

"ต้องดูตอนนี้" ตั้งใจให้เห็นทันที: แถวเป็นกรอบแดงกะพริบช้าๆ อยู่บนสุดของบับเบิล (ถ้ามีหลาย session ก็แสดงทุกแถว) ตัว Angeling มีป้ายแดง "!" และมีเสียงเตือนหนึ่งครั้งตอนเริ่มรอ ถ้าซ่อน Angeling หรือซ่อนบับเบิลไว้ แถวนี้จะโผล่ออกมาเอง ปิดเสียงหรือปิดการโผล่ได้ในเมนู

สถานะที่ค้างนานจะเปลี่ยนเอง: "กำลังทำ" หรือ "ตรวจดู" ที่เงียบเกิน 10 นาที และ "เสร็จแล้ว" ที่เก่ากว่า 30 นาที จะกลายเป็น "พร้อม" ส่วนไฟล์ของ session ที่เงียบเกิน 6 ชั่วโมงจะถูกลบทิ้ง

## แต่ละแถวแสดงอะไร

```
⚙️ ชื่อโปรเจกต์  กำลังทำ · 2/5      ← สถานะ + ความคืบหน้า task list
งาน: prompt ที่คุณสั่ง               ← แบบขยายเท่านั้น
รัน: npm test                        ← สิ่งที่กำลังทำ หรือข้อความสุดท้ายของ Claude
  ✓ ขั้นที่ทำเสร็จ                    ← task list (แบบขยายเท่านั้น)
  ▸ ขั้นที่กำลังทำ
  ○ ขั้นที่ยังไม่ทำ
```

เปิดหรือปิดแต่ละส่วนได้ที่เมนู **แสดงในบับเบิล**

ข้อความที่ Claude Code ส่งเข้ามาเอง (subagent ส่งงานกลับ, งานเบื้องหลังเสร็จ, ข้อความจาก session อื่น) ไม่นับเป็นงานใหม่ บรรทัด "งาน:" และ task list จะคงเดิม แล้วแสดงสิ่งที่เกิดขึ้นในบรรทัดกิจกรรมแทน เช่น "agent ส่งงานกลับมา"

## ธีม

เลือกได้ที่เมนู **ธีม ▸**

| ธีม | หน้าตา |
|---|---|
| Classic (ค่าเริ่มต้น) | บับเบิลชมพูแบบเดิม มี emoji และกรอบสีรอบแถวสำคัญ |
| Minimal สว่าง | พื้นขาว ไม่มี emoji จุดสีหน้าชื่อบอกสถานะ สถานะชิดขวา |
| Minimal มืด | แบบเดียวกันบนพื้นเข้ม |
| Liquid Glass | แบบเดียวกันบน Liquid Glass ของ macOS ย้อมชมพูจางๆ ไม่มีหางบับเบิล ต้องใช้ macOS 26 ขึ้นไป (รุ่นเก่ากว่าเป็นพื้นโปร่งธรรมดา) |
| Tokyo Night | แบบเดียวกันด้วยสีของธีม Tokyo Night |
| Ragnarok | หน้าต่างแบบในเกม Ragnarok Online: แถบชื่อสีฟ้าไล่เฉด กรอบเทา รายการพื้นขาว แถวเรียบไม่มีกรอบ ชี้แล้วเป็นแถบฟ้าอ่อน แถวที่ต้องดูมีแถบสีทางซ้าย ชี้ที่แถวหรือปุ่มแล้วเมาส์เป็นเคอร์เซอร์สามเหลี่ยมฟ้าขาวที่หมุนแบบในเกม |
| ตามระบบ | สลับ Minimal สว่าง / มืด ตาม macOS เอง |

ในธีม Minimal มีแค่แถวที่ต้องดูตอนนี้ แถวเตือน และแถว LINE / Discord / อัปเดตที่มีพื้นสี งานที่เสร็จแล้วบอกด้วยจุดเขียวอย่างเดียว

## แบบย่อ vs แบบขยาย

คลิกลูกศร ⌄ / ⌃ ที่มุมขวาบนของบับเบิลเพื่อสลับ Angeling จำไว้ว่าเลือกแบบไหน

**แบบย่อ** (ค่าเริ่มต้น) แสดงแค่ 2 แถวที่สำคัญที่สุด พร้อมข้อความล่าสุดว่าแต่ละ session กำลังทำอะไร เรียงตาม:
1. session ที่ต้องดูตอนนี้ (กรอบแดง)
1. session ที่ติดปัญหา
1. การเตือนที่ถึงเวลาแล้ว (กรอบสีส้ม) และการเตือนที่จะถึงใน 15 นาที (ดู [ตั้งเตือน](Reminders.md))
1. แถวอัปเดต 🎁
1. session ที่กำลังทำ
1. งานที่เสร็จแล้ว

ที่เหลือรวมเป็นแถว "+N อื่น ๆ" คลิกเพื่อขยาย ถ้าในนั้นมี session ที่รอคุณอยู่ แถวจะเป็นสีส้มและเขียนว่า "มีงานรอคุณ"

LINE และ Discord ไม่เป็นแถวในแบบย่อ แต่แสดงเป็นป้ายตัวเลขบน Angeling แทน

ถ้าซ่อนบับเบิลไว้ จะยังแสดงแถวเตือนที่ถึงเวลาแล้ว และแถวที่ต้องดูตอนนี้

**แบบขยาย** แสดงทุก session พร้อม prompt และ task list รวมถึงแถว LINE และ Discord

ถ้าเปิด[limit การใช้งาน](Usage-Limits.md)ไว้ แถวบนสุดจะแสดง limit คู่กับลูกศร

## ป้ายตัวเลขบน Angeling

ป้าย "!" แสดงตลอด ป้ายจำนวน session แสดงเมื่อซ่อนบับเบิลไว้ ป้าย LINE และ Discord แสดงเมื่อซ่อนบับเบิลหรือย่อรายการไว้

| ป้าย | ความหมาย |
|---|---|
| 🔴 ขวา "!" | มี session ที่ต้องดูตอนนี้ |
| 🔴 ขวา ตัวเลข | จำนวน session ที่กำลังทำหรือติดปัญหา |
| 🟢 ซ้าย | จำนวนข้อความ LINE ที่ยังไม่อ่าน |
| 🟣 ซ้าย (ใต้ป้าย LINE) | จำนวนข้อความ Discord ที่ยังไม่อ่าน (DM และ @mention) |
