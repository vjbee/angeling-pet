# อัปเดตและถอนการติดตั้ง

## อัปเดตเป็นเวอร์ชันล่าสุด

### Angeling บอกเองเมื่อมีเวอร์ชันใหม่

Angeling เช็คกับ GitHub ตอนเปิดแอปและทุก 6 ชั่วโมง ถ้ามีเวอร์ชันใหม่ จะขึ้นแถวสีทอง **🎁 มี Angeling เวอร์ชันใหม่** ในบับเบิล (และในเมนู)

| ทำอะไร | ผลลัพธ์ |
|---|---|
| คลิกแถว 🎁 | อัปเดตเลย: Angeling จะดาวน์โหลดเวอร์ชันใหม่ ปิดตัวเอง แล้วเปิดใหม่เองในไม่กี่วินาที |
| คลิกขวา → ดูว่ามีอะไรใหม่ | เปิดหน้า Release บน GitHub |
| คลิกขวา → ข้ามเวอร์ชันนี้ | ไม่เตือนเวอร์ชันนี้อีก (จะเตือนอีกเมื่อมีเวอร์ชันถัดไป) |
| เมนู → อัปเดต → ตรวจหาเวอร์ชันใหม่ตอนนี้ | เช็คทันที |
| เมนู → อัปเดต → ตรวจอัตโนมัติ | เปิดหรือปิดการเช็คอัตโนมัติ |

การเช็คนี้เป็นการเชื่อมต่อเน็ตอย่างเดียวที่ Angeling ทำ ถ้าผ่านไป 3 นาทีแล้วยังอัปเดตไม่เสร็จ Angeling จะแจ้งว่าอัปเดตไม่สำเร็จ ดูรายละเอียดได้ที่ `~/.claude/angeling-pet/update.log`

> **ใช้เวอร์ชัน 1.2.0 อยู่?** ถ้ากดอัปเดตแล้วค้างที่ "กำลังอัปเดต…" แสดงว่าอัปเดตเสร็จแล้ว แต่แอปตัวเก่ายังไม่ปิด ให้คลิกขวาที่ Angeling → ปิด Angeling แล้วเปิดใหม่ (ปัญหานี้แก้แล้วตั้งแต่ 1.2.1)

### อัปเดตเอง

รันคำสั่งเดิมที่ใช้ติดตั้งอีกครั้ง:

```bash
curl -fsSL https://raw.githubusercontent.com/mobbenxd/angeling-pet/main/get.sh | bash
```

ถ้าติดตั้งแบบ build จากซอร์ส ให้ใช้:

```bash
cd ~/apps/angeling-pet && git pull && ./install.sh
```

ตัวติดตั้งรันซ้ำได้อย่างปลอดภัย: ไม่เพิ่ม hook ซ้ำ และเก็บตำแหน่ง การตั้งค่า กับการเตือนที่ตั้งไว้ไว้ครบ

ดูว่าตอนนี้ใช้เวอร์ชันไหน: `defaults read ~/Applications/Angeling.app/Contents/Info CFBundleShortVersionString`

> หลังอัปเดต macOS อาจถามสิทธิ์ปฏิทินสำหรับ[การเตือน](Reminders.md)ซ้ำ เพราะแอปเวอร์ชันใหม่ถือเป็นแอปใหม่

## ถอนการติดตั้ง

```bash
~/.claude/angeling-pet/uninstall.sh
```

| ลบ | เก็บไว้ |
|---|---|
| `~/Applications/Angeling.app` | `~/.claude/angeling-pet/` (ภาพ, การเตือน, state) |
| LaunchAgent (เปิดเองตอน login) | การตั้งค่า (ตำแหน่ง, ตัวเลือกที่ซ่อนไว้) |
| hook ของ Angeling ใน `~/.claude/settings.json` (hook อื่นไม่ถูกแตะ) | event ที่เพิ่มลงปฏิทินไว้แล้ว |
| status line ของ [limit การใช้งาน](Usage-Limits.md) (คืน status line เดิมของคุณให้) | |

ถ้าจะลบทุกอย่าง รวมถึงไฟล์ การเตือน และการตั้งค่า:

```bash
~/.claude/angeling-pet/uninstall.sh --purge
```

ถ้าเคยให้สิทธิ์ปฏิทิน ให้ลบ Angeling ออกจากรายการใน System Settings → Privacy & Security → Calendars ด้วย
