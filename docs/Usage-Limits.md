# Limit การใช้งาน Claude

Angeling แสดงว่าใช้ limit ของ Claude ไปแล้วเท่าไร ทั้ง limit รายสัปดาห์และ limit 5 ชั่วโมง ปิดไว้ตั้งแต่แรก

## เปิดใช้

คลิกขวาที่ Angeling หรือคลิกไอคอนแถบเมนู แล้วเลือก **📊 แสดง limit การใช้งาน Claude**

ตัวเลขจะขึ้นหลังจาก Claude Code ทำงานครั้งถัดไป ระหว่างนั้นเมนูจะเขียนว่า "รอข้อมูลจาก Claude Code…"

ต้องใช้ Claude Code ที่ login ด้วยบัญชี Claude.ai (Pro / Max) ถ้าใช้ API key จะไม่มีข้อมูล limit และเมนูจะเขียนว่า "บัญชีนี้ไม่มีข้อมูล limit"

## แสดงที่ไหน

| ตอนไหน | หน้าตา |
|---|---|
| บับเบิลเปิดอยู่ | แถวบนสุดของบับเบิล เช่น `สัปดาห์ 62% · 5 ชม. 40%` |
| บัญชีไม่มี limit 5 ชั่วโมง | `สัปดาห์ 71% · รีเซ็ต จ. 11:00` |
| ซ่อนบับเบิล หรือไม่มีงาน | หลอดเล็กใต้ Angeling: ชั้นบนหนาคือรายสัปดาห์ ชั้นล่างบางคือ 5 ชั่วโมง (ถ้าไม่มี 5 ชั่วโมง ชั้นสัปดาห์จะเต็มหลอด) |

เมนู 📊 → **แสดงที่** เปลี่ยนได้:

| ตัวเลือก | ผล |
|---|---|
| บนบับเบิล (หลอดเมื่อซ่อนบับเบิล) | ค่าเริ่มต้น ตามตารางด้านบน |
| บนบับเบิลและหลอด | แถวบนบับเบิล และหลอดใต้ Angeling ตลอด |
| หลอดใต้ Angeling อย่างเดียว | ไม่มีแถว limit บนบับเบิล |

ชี้ที่แถวหรือหลอดเพื่อดูเวลารีเซ็ตและเวลาที่เหลือ เมนู 📊 ก็แสดงข้อมูลเดียวกัน

สีบอกว่าใช้ไปแค่ไหน: ฟ้าเมื่อต่ำกว่า 60% ส้มเมื่อ 60–85% แดงเมื่อเกิน 85%

เมื่อใช้ไปถึง 90% Angeling จะทำหน้า `/omg` หนึ่งครั้งต่อรอบรีเซ็ต

## ใช้ไปแล้ว หรือเหลืออยู่

เมนู 📊 → **แสดงเป็น** เลือกได้ว่าจะแสดง % ที่**ใช้ไปแล้ว** (ค่าเริ่มต้น เหมือน `/usage` ใน Claude Code) หรือ % ที่**เหลืออยู่** แบบหลอด HP ที่ลดลงเรื่อยๆ

สีคิดจากส่วนที่ใช้ไปเสมอ เหลือน้อยจึงเป็นสีแดงทั้งสองแบบ

## ทำงานอย่างไร

Claude Code ส่งข้อมูล limit ให้เฉพาะ status line ไม่ได้ส่งให้ hook ตอนเปิดใช้ Angeling จะ:

1. สำรอง `~/.claude/settings.json` ไว้ที่ `settings.json.angeling-backup`
2. เก็บคำสั่ง status line เดิมของคุณ (ถ้ามี) ไว้ใน `~/.claude/angeling-pet/statusline-orig.json`
3. ตั้ง status line เป็น `~/.claude/angeling-pet/statusline.sh` ซึ่งบันทึกข้อมูลลง `limits.json` แล้วเรียก status line เดิมของคุณต่อ หน้าจอ Claude Code จึงเหมือนเดิม

ตอนปิด Angeling จะคืน status line เดิมให้ ถ้าคุณเปลี่ยน status line เป็นอย่างอื่นไปแล้ว Angeling จะไม่แตะไฟล์ `uninstall.sh` ก็คืนให้เหมือนกัน

ไฟล์ `settings.json` จะถูกจัดรูปแบบใหม่ (ลำดับ key และการเว้นวรรคเปลี่ยน) แต่ค่าเหมือนเดิมทุกอย่าง
